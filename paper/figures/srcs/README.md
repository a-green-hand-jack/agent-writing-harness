# Figure source assets

Raw figure assets (PDF/PNG/JPG) live here, one per figure wrapper in
`paper/figures/`, with a matching basename: `srcs/00_teaser.pdf` backs
`paper/figures/00_teaser.tex`. `.agents/tools/check-structure.py` verifies that
neither a wrapper nor a supported image asset is left unmatched. See
`paper/figures/README.md` for the convention.
