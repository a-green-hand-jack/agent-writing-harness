# Lab Anatomy

`lab/` is the legacy paper-evidence and artifact ledger retained for current validators and real-paper cases. It must not become the research code package or a second experiment runtime.

New paper-first collaboration contracts do not grow here. Human intent belongs in the root contracts; Agent workflows belong in `.agents/`; authored content belongs in `paper/`.

Future code-repository data exchange is intentionally out of scope. Simplify or remove this directory only after existing capabilities and case branches have migrated with equivalent validation evidence.
